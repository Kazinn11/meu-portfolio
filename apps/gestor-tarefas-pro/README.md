# Gestor de Tarefas Pro 🚀

Uma aplicação full-stack de alto desempenho para gerenciamento de tarefas, com foco em produtividade e design premium.

## ✨ Funcionalidades contempladas:
- **Autenticação Completa**: Login e Cadastro com JWT e Bcrypt.
- **Dashboard Inteligente**: Resumo de tarefas, cards de status e progresso diário.
- **Gestão de Tarefas (CRUD)**: Criação, edição, exclusão e filtros por categoria/prioridade.
- **Calendário Interativo**: Visualização mensal das atividades e prazos.
- **Design Premium**: Dark mode, glassmorphism e detalhes em neon.
- **Totalmente Responsivo**: Adaptável para qualquer tamanho de tela.

## 🛠️ Tecnologias Utilizadas:
- **Frontend**: React.js, Vite, Framer Motion, Lucide Icons.
- **Backend**: Node.js, Express, JWT, SQLite.

## 🚀 Como rodar o projeto localmente:

### 1. Pré-requisitos
Certifique-se de ter o **Node.js** e o **npm** instalados em sua máquina.

### 2. Configuração do Backend
1. Navegue até a pasta do backend:
   ```bash
   cd apps/gestor-tarefas-pro/backend
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   npm start
   ```
O servidor estará rodando em `http://localhost:5000`.

### 3. Configuração do Frontend
1. Navegue até a pasta do frontend (em um novo terminal):
   ```bash
   cd apps/gestor-tarefas-pro/frontend
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie a aplicação:
   ```bash
   npm run dev
   ```
A aplicação estará disponível em `http://localhost:5173`.
